# 문자열 덧셈 계산기

## 구현할 기능 목록

- 콘솔에서 문자열을 입력받는다 (Console.readLine() 사용)
- 합산 결과를 "결과 : <숫자>" 형식으로 출력한다
- 빈 문자열 입력 시 0을 반환한다
- 쉼표(,) 또는 콜론(:)을 구분자로 사용한다
- 분리된 문자열을 모두 숫자로 변환해 합산한다
- 커스텀 구분자(`//<구분자>\n`) 형식을 지원한다
- 잘못된 값 입력 시 IllegalArgumentException 발생



<예외 처리 부분>
- 형식 오류: //로 시작했는데 \n이 없거나, //와 \n 사이가 비어 있음
- 빈 토큰: 예) 1,,2 
- 숫자 아님: 예) 1,a,3, 1 2 
- 양수 아님: 0, -1 등 
- 파싱 불가: 너무 큰 수 등 Integer.parseInt 실패
